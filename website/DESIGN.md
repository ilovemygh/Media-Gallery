# Website direction

Product: help PC and Android owners choose the right Media Gallery build.
Character: calm, precise, a little warm.
World: a personal media shelf, with thumbnails, device labels, and tidy metadata.
Moments: a local library preview and a real release list, with color reserved for media.
Signature: “This PC” and “Phone” source labels that show files belong to their devices.

Reference qualities: vgpu.sh’s direct editorial composition, Obsidian’s platform-specific download choices, and Malaka Books’ warm typographic restraint. The product preview is drawn in HTML because the repository contains no real product screenshots.
