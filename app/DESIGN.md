# Media Gallery interface direction

Reading this as a cross-platform library for people browsing their own photos, videos, and music, with a calm editorial surface and direct, familiar controls. Dials: ENERGY 2 / RHYTHM 2 / MOTION 1.

- **Surfaces:** warm near-white in light mode and charcoal in dark mode keep media thumbnails in focus; a muted blue marks selection and primary actions.
- **Typography:** use the platform sans-serif and Material type scale so filenames and metadata stay familiar and readable at different text sizes.
- **Navigation:** keep Home, Library, YouTube, and Devices in the Android bottom bar for one-hand reach; keep the desktop sidebar persistent for broader browsing.
- **Components:** use Material 3 behavior with restrained outlines and modest corner radii so the interface feels consistent without copying another product's visual identity.
- **Motion:** retain standard state transitions and avoid added choreography so scrolling and thumbnail browsing stay steady.
- **Default theme:** start new libraries in light mode because media thumbnails need a quiet canvas and the product references favor an editorial, paper-like surface; keep dark mode available as a saved preference.
